# GET 连接恢复后的无故障验证

该批为诊断复测，不是正式 E3/E4。修正版本使用独立 GET 客户端恢复响应头前的连接失败，上传和控制操作保持原 transport；已返回的对象流不做应用层重放。

Docker 构建中，文件服务 2 项回归通过：复用连接在响应头前断开可恢复；部分正文中断失败且不重放。无故障 300 秒窗口产生 2,709 条探针记录（包括首尾计划 tick），全部成功；结束后 18/18 次下载大小和 SHA-256 匹配，6/6 项权限检查通过。没有观察到原 503，但这不证明其他故障条件下永不失败。

原始请求与服务日志、重建输出、输入源码哈希、Git 状态及前后容器快照均保留。探针优先记录 Nginx 响应中的实际服务请求 ID，已抽查与 Nginx、分享日志对应。工作区含尚未提交的修正代码，正式实验需在提交冻结后用新批次执行。
