# E3 正式结果批次

F1—F5 各三轮，共 15 轮完成。原始状态见 `manifest.json`，结果报告见 [E3-results.md](../../../docs/exp/E3-results.md)。

前九轮 F1—F3 来自 `20261117-154613`，原样复制后按 SHA-256 校验，来源见 `inherited-evidence.json`。续跑前重新核对原项目、六个应用镜像 ID、探针哈希和样本。原批 F4-r1 因 `mc` 对象不存在返回格式被校验器误判而停止；该轮不纳入，F4 的三个正式重复均在本批重新采集。原失败状态及补充复核保留。

每轮有 `probe.csv`、`events.json`、`states.jsonl`、Docker 退出事件、前后容器/版本快照、命令和服务日志，以及恢复后的下载/权限校验。15 轮结束校验合计 270/270 次下载、90/90 项权限检查通过。三次 F5 均确认 JVM 退出码 17、同容器自动重启计数增加及故障开关关闭。

`impact.csv` 为逐业务窗口成功率，`recovery.csv` 为逐次 t0—t5 和恢复耗时，`recovery-summary.csv` 给出三次原值、中位数和范围。图表在 `figures/`，包含 PNG 和矢量 PDF，输入哈希与工具版本见 `figures/provenance.json`。所有数据采用实际采样，不包含离线测试合成记录。

人工场景的恢复从启动命令计时，自动场景从注入命令计时。成功率使用注入至稳定恢复的计划请求窗口；调度滞后和实际发出/返回时刻均保留，不能把图表百分比当作日常服务可用率。论文选取方法见 [材料说明](../../../docs/exp/liu-paper-notes.md)。
