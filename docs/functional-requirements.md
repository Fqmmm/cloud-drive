# 个人网盘功能需求说明

版本：V1.1，2026 年 11 月 9 日。本文定义课程版网盘的目标功能，供小组确认范围、前端设计和业务验收使用。关联：[总体方案](plan.md)、[六容器需求](plan.md#二六容器方案)、[前端需求](phase1/frontend.md)。

## 1. 系统用途与用户

系统为用户提供个人文件保存、目录整理和单文件分享。用户通过浏览器访问统一入口，登录后管理自己的文件；收到分享链接的人可以在链接有效期间按访问规则下载指定文件。

| 用户身份 | 可以完成的操作 |
|---|---|
| 未登录访客 | 注册、登录、打开分享链接、输入提取码、下载获准分享的文件 |
| 已登录用户 | 管理自己的目录与文件、查看容量、创建和取消自己的分享、退出登录 |

每个用户拥有独立的个人空间。登录只赋予本人文件的管理权；知道其他人的文件 ID 也不能查看、下载、重命名、删除或创建分享。有效分享链接提供指定文件的读取能力，接收者不能借此浏览所有者的目录或修改源文件。

## 2. 页面与主要入口

| 页面或区域 | 展示内容 | 主要操作 |
|---|---|---|
| 登录、注册 | 账户、密码、注册资料和校验提示 | 注册、登录、切换表单 |
| 个人文件 | 当前目录、面包屑、文件/目录列表、容量条 | 新建目录、上传、重命名、下载、删除、创建分享 |
| 我的分享 | 创建时文件名、分享地址、访问方式、有效期、链接状态 | 复制链接、取消分享 |
| 分享访问 | 访问规则、提取码输入、授权后的文件名与大小 | 验证提取码、下载 |
| 用户区域 | 昵称、账户名、退出入口 | 查看基础资料、退出登录 |

“我的分享”可作为个人文件页的标签页实现。页面组织沿用现有界面，入口覆盖上述操作即可。

## 3. 账户与登录

### FR-01 注册个人账户

用户输入账户名、密码、昵称和邮箱，提交成功后进入登录流程。账户类型固定为个人账户。

| 字段 | 规则 |
|---|---|
| 账户名 | 3—32 个英文字母、数字或下划线；按小写归一后保存和判重 |
| 密码 | 8—64 个字符，输入框隐藏内容 |
| 昵称 | 1—32 个字符，允许中文 |
| 邮箱 | 有效邮箱格式，系统内唯一 |

前后端采用同一校验规则。必填项缺失、账户名或邮箱已注册时，显示对应提示并保留非敏感表单内容。首版采用普通注册，邮箱验证、找回密码和密码修改留作扩展。

### FR-02 登录、基础资料与退出

登录时账户名采用与注册相同的小写归一规则，例如注册输入 Alice 后可用 alice 登录。用户使用账户名和密码登录，成功后进入个人文件根目录，显示昵称和容量。凭证错误时显示统一的账户或密码错误提示。登录状态在凭证有效期内支持页面刷新。

凭证过期后，私有操作提示重新登录并跳转登录页。退出登录清除本浏览器中的登录凭证和用户信息；已发出的短期凭证按自身有效期到期，首版不提供跨设备强制退出。公开分享页独立处理提取码错误，避免将其当作用户登录过期。

## 4. 个人文件与目录

### FR-03 浏览个人空间

进入个人文件页时列出根目录的直接内容。列表展示名称、文件/目录类型、文件大小和创建时间；目录大小可显示占位符。点击目录进入下一层，通过面包屑返回上层。空目录显示空状态和上传、新建入口。

列表只显示当前用户的活动记录。首版浏览按目录分层，搜索、排序自定义和批量操作留作扩展。

### FR-04 创建、重命名与删除目录

用户可在根目录或已有目录下创建子目录、重命名目录和删除空目录。文件与目录在同一父目录下共用名称空间；同名操作被拒绝，提示更换名称。

名称长度为 1—255 个字符，允许中文和空格；名称不能全为空白，不能是 `.` 或 `..`，不能包含 `/`、`\` 或控制字符。先去除首尾空白，再执行校验。同名比较采用数据库统一确定的排序规则，并在首次验收记录中注明大小写行为。

非空目录删除被拒绝，提示先删除内容。首版不提供递归目录删除、目录下载和目录分享。

### FR-05 上传文件

用户选择一个文件上传到当前目录，页面显示传输状态并防止重复点击。单文件默认上限为 100 MiB，账户默认容量为 10 GiB。页面同时显示单文件限制和剩余容量，最终由服务端校验。

上传成功后，新文件出现在当前目录，已用容量增加。文件保留原文件名，重名时拒绝并提示用户先修改名称。中文和带空格文件名可正常显示和下载。

上传超限、空间不足或服务暂不可用时，显示原因；失败上传不增加已用容量，不产生可下载的成功记录。网络中断后允许用户重新选择文件重试，首版不提供断点续传。

### FR-06 下载与重命名文件

所有者可下载当前空间中的普通文件，浏览器按文件名保存，文件内容与上传内容一致。下载中断时提示失败，用户可重新发起下载。

文件重命名只改变名称，不改变内容、所属目录或已用容量。名称规则与目录相同；重名时拒绝。重命名后原分享仍指向同一文件，下载使用当前名称。“我的分享”保留创建时的名称快照，便于辨认历史记录。

### FR-07 永久删除文件

删除前显示文件名和“永久删除，无法在网盘中恢复”的确认。确认成功后，文件从个人列表消失，已用容量扣减，原分享的新访问失效。重复请求不会重复扣减容量。

首版不提供回收站和恢复入口。物理对象清理由后台完成，用户看到的删除结果以文件是否失效为准；清理延迟不会使已删除文件重新可访问。文件替换为新上传记录后，旧分享也不会自动指向新文件。

### FR-08 查看容量

容量条显示总容量、已用容量及可用容量，上传或删除成功后刷新。默认值为 10 GiB，部署可调整；目录不占容量，活动文件按实际字节数计算。并发上传同样受配额限制，已用容量保持在 0 与总容量之间。

后台尚未清理的已删除对象不计入用户已用容量。容量展示可换算为 MiB/GiB，后台计量统一使用字节。

## 5. 单文件分享

### FR-09 创建与复制分享

用户为自己的一个普通文件创建分享，选择公开访问或提取码访问，选择 1 天、7 天、30 天或永久有效。提取码由系统生成，固定为六位数字，允许前导零，输入和传输按字符串处理；创建成功时显示一次，并提供复制链接及提取码的操作。后续不提供明文提取码找回；遗失后可取消原分享并重新创建。

同一个文件允许创建多个独立分享，取消某个分享不影响其他分享。分享链接指向浏览器可访问的前端入口。创建失败时不显示虚假的成功链接。

### FR-10 匿名访问与下载

访问分享不要求注册或登录。公开分享可直接显示文件信息；提取码分享先展示输入界面，验证通过后才显示文件名、大小和下载入口。提取码输入错误时保留在当前页并提示重试。仅对错误提取码尝试计数和限流，触发限制时提示稍后再试；公开访问和正确提取码请求不受该错误次数限制。限流窗口和阈值见[分享服务需求](phase1/share-service.md)。

下载时重新检查提取码、有效期、取消状态及文件可用性。接收者仅能获取该分享对应的单个文件，不能更换文件 ID 来下载其他内容。文件服务暂不可用时显示稍后重试，服务恢复后有效链接可以继续使用。

### FR-11 查看与取消分享

我的分享保留并列出本人创建的未取消、已取消和已过期记录，包括创建时文件名、创建时间、访问方式、有效期和链接状态。链接状态按分享记录显示“未取消”“已取消”或“已过期”；“未取消”表示链接记录未取消且未到期，源文件是否仍可用在实际访问时检查。

用户可取消自己的分享，确认后后续新访问和下载被拒绝。重复取消视为相同结果。已开始传输的下载按当前连接结束，首版不要求中途强制切断。

### FR-12 分享失效提示

| 情况 | 页面行为 |
|---|---|
| 链接不存在 | 显示分享不存在 |
| 提取码缺失或错误 | 要求输入或重新输入，不显示受保护文件详情 |
| 链接已过期 | 显示分享已过期 |
| 所有者取消分享 | 显示分享已取消 |
| 源文件已删除 | 显示文件已失效，禁止新下载 |
| 相关服务暂不可用 | 显示服务暂不可用，允许稍后重试 |

到期时间由服务端判定，客户端时钟不改变授权结果。相同 HTTP 状态下的失效原因通过业务码区分，前端使用[分享错误码表](phase1/share-service.md#2-对外-api)映射提示；网关或网络错误无法提供业务码时显示通用错误提示。

## 6. 核心操作示例

场景一：用户注册并登录，新建“课程资料”目录，上传 `实验说明.pdf`。文件出现在列表中，容量增加；下载后文件内容完整。用户重命名文件，重新打开页面仍看到新名称。

场景二：用户为该文件创建 7 天有效的提取码分享，将链接和提取码交给接收者。接收者在未登录浏览器中打开链接，输入正确提取码并下载。输入错误提取码或修改目标文件标识均无法下载。

场景三：所有者取消分享，接收者再次访问时看到取消提示；源文件仍在个人空间。另建一个有效分享后永久删除源文件，新分享访问也随之失效。

场景四：用户 U1、U2 各自上传文件。U2 修改请求中的文件 ID，仍无法列出、下载、删除或分享 U1 的私有文件；U1 创建的有效分享只授予指定文件的读取能力。

## 7. 课程版范围与验收

| 类别 | 本版范围 |
|---|---|
| 账户 | 个人账户、注册登录、基础资料、退出 |
| 文件 | 单文件上传下载、浏览、重命名、永久删除 |
| 目录 | 分层浏览、创建、重命名、空目录删除 |
| 容量 | 固定总容量、用量展示、超额拒绝 |
| 分享 | 单文件、公开或提取码、有效期、列表、取消、匿名下载 |
| 扩展 | 去重、回收站、移动复制、搜索、批量操作、断点续传 |
| 移出课程首版 | 团队、邀请、Flowable、自定义 RBAC、会员、私密空间、Redis、目录分享、SSE 进度 |

业务验收覆盖 FR-01—FR-12。刘骐语 为每项编号建立用例，记录操作、输入、预期、实际结果和版本；至少使用两个用户和一个未登录浏览器，验证正常流程、权限隔离、超限与分享失效。

部署验收与四组实验分别见[总体方案](plan.md)和[实验方案](plan.md#五阶段二四组实验)。功能要求由本文统一维护，容器文档负责说明服务实现边界。功能调整时同步修改相关页面、容器需求和验收用例。
