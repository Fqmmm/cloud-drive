## 功能验收覆盖

逐项操作和预期由 `scripts/smoke/functional.py` 的断言及 [功能需求](functional-requirements.md)定义。执行入口直接复用已有脚本，同时保存版本、环境、逐用例 PASS/FAIL 与异常；不会把 API 通过写成浏览器通过。

| 编号 | 输入与操作、预期 |
|---|---|
| FR-01 | 两用户注册，正常进入登录流程；账户归一判重、重复邮箱、非法/缺失字段被拒绝，密码输入遮罩且数据库强散列 |
| FR-02 | 正误密码、刷新、退出、伪造/过期 JWT；资料字段正确，私有入口拒绝无效凭证并跳转 |
| FR-03 | 空目录、子目录、面包屑和用户空间隔离 |
| FR-04 | 中文及空格目录、重命名、空删；非法/同名名称、非空删除、目录下载/分享被拒绝 |
| FR-05 | 上传成功、100 MiB 边界及超限、失败重试、传输状态与防重复点击 |
| FR-06 | 原名下载、重命名、原分享同步当前名、SHA-256；截断下载提示失败并允许重试 |
| FR-07 | 永久删除、重复删除、名称复用不复活旧分享、配额只归还一次 |
| FR-08 | 总量/已用/可用容量、临时限额及并发超额拒绝；只修改本次随机测试用户，结束恢复 |
| FR-09 | 公开/六位提取码、前导零、1/7/30 天及永久；不合法分享设置被拒绝 |
| FR-10 | 匿名公开/正确提取码下载、错误码和限流、下载再次授权、同源请求 |
| FR-11 | 本人分享快照、归属隔离、复制/取消、取消幂等与历史状态 |
| FR-12 | 取消/过期/删除源文件/链接不存在的差异提示，真实文件服务及 MinIO 故障与恢复 |

正式结果以本轮 `experiments/acceptance/<run-id>/results.json` 和服务日志为准。论文引用必须带批次、源码提交、实验参数、原始记录路径和统计口径。
